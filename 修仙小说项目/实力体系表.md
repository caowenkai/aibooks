# 实力体系表

## 使用说明
本文件用于追踪主角和配角的实力成长，确保战力体系不崩坏。

**战力标准**：
- 同阶：境界相同
- 越一阶：击败高一境界（如筑基击败金丹）
- 越两阶：击败高两境界（如金丹击败元婴）
- 无敌：同阶横扫，越阶战斗

## 境界战力标准

### 练气期（1-9层）
- **同阶差距**：每层差距20%
- **战斗特点**：基础法术、灵气操控
- **越阶挑战**：需要特殊体质或法宝

### 筑基期（初、中、后、圆满）
- **同阶差距**：每个小境界30%
- **战斗特点**：御剑飞行、中级法术
- **越阶挑战**：越一阶需要50%实力差距或底牌

### 金丹期（初、中、后、圆满）
- **同阶差距**：每个小境界40%
- **战斗特点**：金丹法相、大神通术
- **越阶挑战**：越一阶需要实力碾压或多重底牌

### 元婴期（初、中、后、圆满）
- **同阶差距**：每个小境界50%
- **战斗特点**：元婴出窍、领域雏形
- **越阶挑战**：越一阶已经是天才级别

### 化神期（初、中、后、圆满）
- **同阶差距**：每个小境界60%
- **战斗特点**：领域神通、元神化形
- **越阶挑战**：越一阶是传说级别

### 合体期（初、中、后、圆满）
- **同阶差距**：每个小境界70%
- **战斗特点**：天人合一、借用天地之力
- **越阶挑战**：极少见，需要逆天机缘

### 渡劫期（初、中、后、圆满）
- **同阶差距**：每个小境界80%
- **战斗特点**：触碰仙道、法相天地
- **越阶挑战**：几乎不可能

### 大乘期（初、中、后、圆满）
- **战斗特点**：仙凡分界，几近仙修
- **战力表现**：一人可灭一国

## 战斗描写原则

### 同阶战斗
- 强调技巧、经验、法宝品质
- 战斗过程占60%，结果占40%
- 突出战术和智慧

### 越阶战斗
- 必须有合理理由（特殊体质、顶级法宝、环境优势）
- 强调底牌和爆发
- 战斗过程占40%，结果占60%

### 压级战斗（高打低）
- 简短描写，突出实力差距
- 强调境界压制
- 不占篇幅，一两招解决

## 实力崩坏预防

### 常见问题
1. **主角实力提升过快** → 按照表格严格控制
2. **反派战力忽高忽低** → 提前设定实力等级
3. **配角成长过快** → 配角始终落后主角1-3个小境界
4. **境界体系混乱** → 严格按照境界划分

### 解决方案
1. **参考本表**：写作前查看本表
2. **战斗预演**：重要战斗前预演战力对比
3. **定期检查**：每3个任务检查一次战力体系
4. **读者反馈**：根据读者反馈调整

## 使用建议

### 写作时
1. 查看主角当前境界和战力表现
2. 确定对手实力，预估战斗难度
3. 设计合理的战斗过程
4. 避免无底线越阶

### 检查时
1. 战斗结果是否符合战力表格
2. 境界提升是否合理
3. 是否有战力崩坏迹象

### 调整时
1. 如果发现战力问题，及时调整
2. 重大战力调整需要重新评估后续战斗
3. 保持战力体系的严谨性
