# 人物设定卡

## 主角 - 林逸

### 基本信息
- **姓名**：林逸
- **年龄**：15岁（开篇）→ 约150岁（飞升）
- **出身**：东荒边陲青石镇林家
- **身份**：凡人 → 外门弟子 → 内门弟子 → 宗门支柱 → 救世主 → 仙修

### 性格特点
- **核心特质**：坚毅、聪慧、重情义、杀伐果断
- **成长轨迹**：
  - 前期：谨慎、隐忍、善于学习
  - 中期：自信、果决、有主见
  - 后期：霸气、超然、心怀苍生
- **价值观**：不圣母但有底线，不滥杀但有仇必报，重视亲情友情

### 修炼天赋
- **灵根**：五行杂灵根（隐藏的特殊体质"天生道体"）
- **修炼速度**：初期普通，中后期突飞猛进
- **特殊天赋**：
  - 炼丹：宗师级（任务8起）
  - 炼器：大师级（任务7起）
  - 阵法：宗师级（任务12起）
  - 剑道：天赋型（任务6起）

### 金手指 - 古玉残片
**解锁时间线**：
- 任务1：获得古玉，未知作用
- 任务2：发现能催熟灵药
- 任务3：完全激活，获得上古传承
- 任务6：与虚天殿共鸣，确认为殿主信物
- 任务10：吸收雷劫之力，进化
- 任务14：觉醒，得知是镇压天魔的关键
- 任务16：封印天魔通道，古玉受损
- 任务18：牺牲自己挡劫雷，与林逸融合
- 任务20：完全融合，实力暴涨

### 功法体系
1. **主修功法**：
   - 《太初诀》（任务1-20，不断进化）
   - 上古剑仙传承（任务6起）
   - 龙族功法（任务11起）

2. **辅修功法**：
   - 炼丹术（任务4起）
   - 炼器术（任务7起）
   - 阵法（任务12起）

### 武器装备
- **本命法宝**：虚天剑（任务6获得，不断进化）
- **防御法宝**：古玉护体（进化为护体罡气）
- **辅助法宝**：储物戒、传音符、防御符箓等

### 实力成长
| 时期 | 境界 | 战力表现 | 代表战绩 |
|------|------|----------|----------|
| 凡尘 | 练气1-6 | 同阶无敌 | 击败筑基初期师兄 |
| 宗门 | 练气7-筑基中 | 越一阶 | 秘境中筑基 |
| 金丹 | 金丹初-圆满 | 越两阶 | 斩杀元婴初期 |
| 元婴 | 元婴初-圆满 | 越三阶 | 斩杀化神初期 |
| 化神 | 化神初-圆满 | 越四阶 | 斩杀合体期 |
| 合体 | 合体-渡劫 | 同阶无敌 | 击败渡劫后期 |
| 仙界 | 渡劫-飞升 | 跨越式 | 斩杀仙界大能 |

## 主要配角

### 1. 苏清雪（女主1）
- **身份**：青云宗内门师姐 → 宗门圣女 → 飞升仙界
- **性格**：清冷、聪慧、专一
- **感情线**：任务2相识，任务4互生好感，任务9表白，任务17成亲，任务20随林逸飞升
- **修为**：始终略低于林逸1-2个小境界
- **特点**：冰灵根，修炼冰系功法，是林逸的温柔港湾

### 2. 王胖子（死党）
- **身份**：外门弟子 → 内门弟子 → 宗门长老
- **性格**：憨厚、忠诚、搞笑担当
- **作用**：情报来源、搞笑调剂、关键时刻信任
- **结局**：飞升仙界，成为林逸在仙界的助力

### 3. 林长老（恩师）
- **身份**：青云宗长老，林逸引路人
- **性格**：严厉但关心弟子
- **结局**：在宗门大战中牺牲，林逸为其复仇

### 4. 神秘女修（女主2）
- **身份**：来历神秘，身世复杂
- **性格**：妖娆、神秘、强大
- **感情线**：任务8相识，任务12表白，任务17三人和解
- **修为**：初期与林逸相当，后期被超越
- **特点**：魔修出身，为林逸改邪归正

### 5. 天道盟主（反派）
- **身份**：天道盟创立者，化神期大能
- **动机**：妄图颠覆修仙界，获得古玉
- **结局**：任务13被林逸击杀

### 6. 域外天魔（最终反派）
- **身份**：域外天魔首领，仙界堕仙
- **动机**：入侵三界，吞噬生灵
- **结局**：任务16被林逸封印

### 7. 仙界统治者（最终BOSS）
- **身份**：仙界至高统治者
- **动机**：维持统治，封印林逸父母
- **结局**：任务20被林逸击败

1. **虚天殿**：上古剑仙留下的秘境

3. **域外天魔**：来自界外的邪恶势力

## 修炼体系

### 境界划分
1. **练气期**：1-9层，吸收天地灵气
2. **筑基期**：初期、中期、后期、圆满，铸造道基
3. **金丹期**：初期、中期、后期、圆满，凝结金丹
4. **元婴期**：初期、中期、后期、圆满，孕育元婴
5. **化神期**：初期、中期、后期、圆满，元神化形
6. **合体期**：初期、中期、后期、圆满，元婴与肉身合一
7. **渡劫期**：初期、中期、后期、圆满，渡过天劫
8. **大乘期**：初期、中期、后期、圆满，仙凡分界
9. **飞升**：飞升仙界，成为仙修

### 仙界境界（任务18-20）
- **仙修**：下品、中品、上品、极品
- **仙王**：仙界一方霸主
- **仙尊**：仙界顶尖强者
- **仙帝**：仙界统治者

### 特殊体质
- **天生道体**（林逸）：修炼速度快，悟性极高
- **九阴绝脉**（女主2）：修炼魔道功法天赋极高
- **纯阳之体**（配角）：修炼火系功法天赋极高

## 世界观设定

### 地理格局
1. **东荒**：边陲之地，林逸出身地
2. **中州**：修仙界核心，天才云集
3. **海外**：与大陆隔绝，有独特体系
4. **蛮荒之地**：危险区域，妖兽横行
5. **仙界**：更高维度的世界

### 修炼资源
- **灵石**：下品、中品、上品、极品
- **灵草**：1-9品，9品最珍贵
- **丹药**：1-9品，分等级
- **法宝**：法器、灵器、法宝、道器、仙器
- **功法**：黄、玄、地、天、仙五阶

### 时间设定
- 修仙界岁月与凡间不同
- 元婴期寿元可达千载
- 化神期寿元可达万载
- 飞升后寿元无穷
