# `batch01_chunk09a_micro` 本地续写产物

生成时间：2026-03-18 15:52 CST

## Text

第一步踩上活坡时，脚下便是一阵极轻的松响。

那不是石头立时塌落的声音，而是整片碎石皮在冻夜里被人一压，先齐齐往下一滑了半寸，像一张绷紧多时的旧席面忽然被扯皱。许临渊肩背发紧，脚却不敢立刻回收，只能顺着那半寸滑势贴壁沉下重心，待脚底碎石重新咬住坡面，才把第二口气慢慢吐出来。

身后断羊槽中的白丝显然也察觉了。

最靠右的两缕细丝先是微微扬起，继而一点点朝活坡这边探来，动作极慢，像毒虫试热冷。它们不敢真扑，只沿着壁边碎石上方轻轻拂过，所过之处，石面上竟立时凝起一层薄白霜壳。几枚本就欲落的碎石被霜意一逼，当即“簌簌”滑下，撞得坡下黑暗里回声空空。

陌客伏在他肩上，气声更低：“别停……越停，坡越活。”

许临渊嗯了一声，眼睛却只盯前头。

三步之外，果真有一道横裂。裂缝不宽，却正好可塞进半只脚掌，若踩得准，便能借这一点实处把两个人的分量稳住。可那裂口左侧偏偏挂着一块巴掌大的松石，若伸脚时蹭着，多半整片坡皮都要跟着一并泻下。

他先将陌客往肩上更顶了顶，随即右脚向前虚点半下，待摸到那缝的边沿，才猛地沉实。

这一脚落稳，后背的冷汗才真出了。

可也就在同一瞬，断羊槽中忽有一缕白丝舍了原处，贴着右壁外沿疾掠而来。

它竟也学会借活坡试路。

那东西速度不快，却极阴。并不直扑人身，而是专往许临渊脚下那道横裂旁边钻，显然是想先毁他唯一能借力的地方。若叫它逼得那道裂缝结霜碎开，两人不用它近身，自己就得连人带石滚下坡去。

许临渊眼角骤沉，想也不想，反手就从腰后抽出药铲，铲背不劈白丝，反倒狠狠磕在自己脚后半尺那块本就悬着的松石上。

“喀！”

那块松石应声而断，带得周围一串碎石猛地往下泻去，像一蓬骤然塌开的灰雪，正冲着那缕白丝掩过去。白丝似也没料到他会在这种地方主动震坡，尖尖一折，想往上抽回，可活坡最怕的就是这一记带头。一块落，十块随，十块落，半坡都活。

转眼之间，右壁外便起了一道不大不小的碎石浪。

那缕白丝被卷在其中，先是硬撑着亮了一瞬，像霜刀劈进泥沙，紧接着便被更多翻下来的石片、冻土与枯根一并压住，只来得及发出一记极细极尖的裂鸣，便被拖着滚下了坡。

断羊槽里其余几道白丝顿时齐齐一震。

它们这回不是往前探，反倒齐齐往后一收，像是第一次真正吃痛，终于明白这块活坡不只是人的险地，也是它们自己的险地。

许临渊却没有半分得意。

他很清楚，方才那一下只是借山势抢了半口气，绝不是把路打通了。活坡一旦被自己震活，接下来每一步都会比先前更险。果然，还不待坡下那阵碎石声散尽，他脚底借力的那道横裂便也跟着松了松，边缘碎屑簌簌往外掉，像一口旧牙被人硬生生撬开。

陌客在他耳边低低吸了口气：“再往前……两步，有老松根。”

许临渊不再回头看那些白丝，只盯着前方暗里隐约浮出的半截黑影。那应当便是陌客所说的老松根，只要够到，便能借它横拉过去，离开最活的这一截坡皮。

他咬紧牙，提着一口气往前挪。

第一步，脚底整片碎石往下溜了近一尺，逼得他整个人狠狠撞上右壁，肩骨都震得发麻；第二步方才探出，身后断羊槽里便又传来一阵细密寒鸣，显然那些白丝不肯就此放过，已沿槽口重新换位，想从更高处压下来。

可这两步终究没白拼。

许临渊指尖往前一伸，终于扣住那道突出的老松根。根皮早已冻硬，粗粝得像铁，可这一刻落在掌中，却比任何金玉都叫人心定。他立时借力一扯，将自己和陌客一道横横拖过半丈，重重摔进松根下方一处稍稳的凹窝里。

两人方一落定，先前立足那片活坡便“哗啦”一声大泻下去。

碎石如雨，整段坡皮连着霜壳一并塌落，连断羊槽外缘都被带塌了一角。其间还夹着两三记极尖的裂音，像是有新的白丝趁乱逼来，却反被这场突塌一并卷下了坡底。

山坳里一时回声四荡。

许临渊伏在松根下，胸口起伏得厉害，半晌才抬头望了一眼。原先那条直逼断羊槽的活坡，此刻已塌成一道新鲜断面，下面黑得不见底，上面白丝虽仍未尽绝，却一时再难轻易铺过来。

他终于低低吐出一口气：“这下，该轮到它们绕路了。”

陌客靠着松根，脸白得像纸，眼里却第一次有了点近乎清醒的亮色：“你方才那一下……不是在逃，是在试着杀它。”

“杀不杀得成另说。”许临渊抹去颊边碎砂，重新把人扶起，“至少得先教它知道，追得太近，也会掉下去。”

前头林影更深，东折之路终于露出半截可走的轮廓。

而后头那些东西，也果然开始重新找路了。
