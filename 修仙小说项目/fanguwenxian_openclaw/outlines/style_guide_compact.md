# 《凡骨问仙》紧凑风格手册

## 来源

来自远端 `style_compact` 成功产物，已整理为后续正文 prompt 可直接引用的约束。

## 正文规则

1. 行文取古雅正声，不染轻浮俗气。
2. 叙述凝练沉稳，少作碎嘴铺陈。
3. 句式长短相济，务求气脉连贯。
4. 对话克制有度，勿作插科打诨。
5. 情绪含蓄内敛，忌直白宣泄。
6. 修炼描写庄重，突出道机玄意。
7. 斗法描写清峻，重势、重理、重险。
8. 人物言行守礼，各依身份心性。
9. 用词典整洁净，少涉今人口癖。
10. 章节节奏稳健，忌水词拖沓。
11. 旁白不卖俏，不与读者嬉笑。
12. 通篇气质苍茫肃穆，守传统仙侠味。

## 禁止事项

1. 禁用网络热梗与弹幕腔。
2. 禁用吐槽体与段子式对白。
3. 禁用现代职场校园语感。
4. 禁用连续感叹问号堆叠。
5. 禁用废话复述与情绪灌水。
6. 禁用自嘲卖萌式旁白。

## 修正建议

1. 口语句改书面句，删虚词赘语。
2. 轻佻对白压低，补身份分寸。
3. 直白情绪收束，改为动作映照。
4. 水账描写精简，提炼冲突道意。

## 用法

- 后续所有正文类 prompt 都应显式引用本文件。
- 若远端后续产出更完整的 style guide，可以在此基础上增补，而不是推翻。
