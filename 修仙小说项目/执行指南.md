# 修仙小说项目执行指南

## 如何使用这个大纲

### 方式一：分批执行（推荐）
将20个任务分成5批，每批4个任务：
- 第1批：任务1-4（凡人起步，20万字）
- 第2批：任务5-8（宗门成长，20万字）
- 第3批：任务9-12（金丹到元婴，20万字）
- 第4批：任务13-16（中州到化神，20万字）
- 第5批：任务17-20（拯救到飞升，20万字）

### 方式二：分20个独立子任务
每个任务5万字，可以作为独立的写作任务：
```
任务1: "请根据大纲《凡尘觉醒》章节，撰写5万字的修仙小说开篇..."
任务2: "请根据大纲《初入宗门》章节，撰写5万字的修仙小说..."
...
```

### 方式三：使用sessions_spawn（OpenClaw专属）
使用OpenClaw的sessions_spawn功能，让子AI并行写作：
```
spawn: "请根据任务1的大纲，撰写5万字修仙小说《天道逆行》第一章..."
```

## 每个任务的执行模板

```markdown
# 任务X：[章节名称] - 5万字

## 前置要求
- 完成任务1至任务X-1
- 理解前文情节和人物关系

## 本任务要求
1. **字数**：严格控制在5万字左右（48,000-52,000）
2. **章节划分**：建议分为8-10个小节
3. **核心情节**：[从大纲复制]
4. **关键冲突**：[列出本任务的2-3个主要冲突]
5. **人物成长**：[主角在本任务的心境/实力变化]

## 风格要求
- 文笔流畅，符合修仙小说风格
- 战斗描写要有策略和意境
- 对话要符合人物性格
- 适当加入诗词、功法口诀等元素
- 伏笔埋设要自然

## 输出格式
- Markdown格式
- 包含章节标题和小节标题
- 重要对话和功法口诀用引用格式
- 战斗场面要有画面感

## 注意事项
- 不要跳过重要情节
- 人物行为要符合人设
- 实力提升要有合理解释
- 为后续任务埋下伏笔
```

## 质量控制检查清单

每个任务完成后，检查：
- [ ] 字数是否达标（5万字左右）
- [ ] 核心情节是否完整
- [ ] 人物行为是否合理
- [ ] 是否有明显的逻辑漏洞
- [ ] 是否为后续埋下伏笔
- [ ] 战力体系是否崩坏
- [ ] 文笔是否流畅

## 连贯性保证

### 人物设定卡
创建统一的人物卡片，确保各任务中人物性格一致：
```
【主角-林逸】
- 性格：坚毅、聪慧、重情义、杀伐果断
- 特点：修炼天赋、炼丹天赋、阵法天赋
- 金手指：古玉残片（逐步解锁）
- 成长轨迹：练气→筑基→金丹→元婴→化神→合体→渡劫→飞升
```
